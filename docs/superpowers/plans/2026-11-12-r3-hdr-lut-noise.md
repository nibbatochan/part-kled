# R3 HDR Scene, LUT Grade, Blue-Noise Grain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use checkbox syntax.

**Goal:** Add a 16-bit scene and bloom chain (8-bit fallback), a LUT colour grade with 8 grades, and a blue-noise option for the film grain, all off by default.

**Architecture:** New `Params` fields first (`hdrOn`, `lutOn`, `blueGrainOn`, `finish.lutId`, `finish.lutAmount`), mapped through `WebEngine` into `PostParams`, drawn by `src/lite/Post.ts`. Grades live in one atlas PNG (33 x 33 slices side by side, one row of slices per grade) built from the licensed `.cube` files by `tools/luts/build_atlas.py`. Textures load lazily, only when their control is first switched on.

**Spec:** none (owner approved the design in chat: 16-bit buffer, LUT picker, blue-noise grain, all off by default; neutral, black-and-white and cross-process grades generated by us). Research: `docs/RESEARCH_EFFECT_RECREATION.md` section 8 row R3; assets: `docs/RESEARCH_LUT_PRESETS.md`.

## Global Constraints

- Everything off by default; with all three off the frame is identical to now (verify-finish "all off" frame must match the pre-R3 baseline).
- `core/` and `lite/` import no UI. Params first, then shader, then UI.
- Texture units: LUT atlas 14, blue noise 15 (units 4 to 13 are taken).
- Licences: slay LUTs need the credit line "LUTs: slay (CC BY 4.0)" shown in the app next to the grade control; DuskTide (MIT) notice kept in `public/luts/LICENSES.md`; blue noise is CC0.
- Hero bundle stays under 200 kB gzip (`npm run build:hero`).
- 16-bit needs `EXT_color_buffer_float` or `EXT_color_buffer_half_float`; without it, or if the framebuffer is incomplete, fall back to RGBA8 and report it (`Post.hdrActive`).
- Android does not get these passes.

## Review Focus

- No LUT file yet (still loading) or a failed load: the frame must show no grade and no error.
- Switching 16-bit on and off while passes are on: all targets remade, no GL error, no leak.
- Resize with 16-bit on.
- Grain on a flat dark field: blue-noise mode must not show tiling seams (64 px repeat) at any cell size.
- EFFECTS RESET clears the three new flags.
